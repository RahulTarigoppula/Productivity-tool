# Productivity tool

A local, single-window, all-in-one app for personal use: open, create, edit, convert and save office documents, spreadsheets, presentations, PDFs, Markdown, and any text or code file in one tabbed workspace, on Windows first, then Android, then Mac and iPhone/iPad.

**Stage:** v0.1 of the Windows app — text, code, Markdown, CSV and PDF editing; Word, Excel and PowerPoint previews.

- The app: [apps/desktop](apps/desktop/README.md) (install, features, keyboard, build, known gaps)
- Plans, research and user flows: [docs/README.md](docs/README.md)
