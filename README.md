# Productivity tool

A local, single-window, all-in-one app for personal use: open, create, edit, convert and save office documents, spreadsheets, presentations, PDFs, Markdown, and any text or code file in one tabbed workspace, on Windows first, then Android, then Mac and iPhone/iPad.

**Stage:** research and planning. No application code yet.
